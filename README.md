# حسابیار؛ ساخت نسخه ویندوز (.exe) و اندروید (.apk)

## روش پیشنهادی: ساخت خودکار در GitHub (بدون نصب هیچ برنامه‌ای)
1. در github.com یک حساب رایگان بسازید و یک Repository جدید (ترجیحاً Private) ایجاد کنید.
2. همه فایل‌های این پوشه (از جمله پوشه پنهان `.github`) را در آن آپلود کنید.
   اگر پوشه `.github` آپلود نشد: Add file ← Create new file، نام فایل را `.github/workflows/build.yml` بنویسید و محتوای فایل `build.yml` را در آن بچسبانید.
3. به تب Actions بروید، گزینه Build Hesabyar را انتخاب کنید و Run workflow را بزنید.
4. حدود ۵ تا ۱۰ دقیقه صبر کنید. در انتهای صفحه اجرا، بخش Artifacts دو فایل دارد:
   - hesabyar-windows-exe: فایل نصب ویندوز
   - hesabyar-android-apk: فایل نصب اندروید

## نصب
- ویندوز: فایل exe را اجرا کنید. چون برنامه امضای دیجیتال ندارد، ویندوز هشدار SmartScreen می‌دهد؛ More info ← Run anyway.
- اندروید: فایل apk را به گوشی منتقل کنید و نصب از منابع ناشناس را برای همان برنامه (مرورگر یا مدیر فایل) مجاز کنید.

## ساخت روی کامپیوتر خودتان (اختیاری)
ویندوز (نیازمند Node.js 20):
    npm install
    npm start            (اجرای آزمایشی)
    npm run dist:win     (ساخت فایل نصب در پوشه dist)

اندروید (نیازمند Node.js 20، JDK 17 و Android Studio):
    npm install
    npx cap add android
    npx cap sync android
    npx cap open android   (در Android Studio: Build ← Build APK)

## نکته‌ها
- اطلاعات هر نسخه (ویندوز، اندروید) جدا و روی همان دستگاه ذخیره می‌شود. برای انتقال از «تنظیمات ← پشتیبان‌گیری و بازیابی» استفاده کنید.
- در اندروید، پشتیبان از منوی اشتراک‌گذاری گوشی ارسال یا ذخیره می‌شود.
